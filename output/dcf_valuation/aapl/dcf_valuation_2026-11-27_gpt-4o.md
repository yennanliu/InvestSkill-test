## WACC 計算
加權平均資金成本（WACC）是DCF模型的關鍵組成部分，通過分析蘋果的資本結構來確定：

- **成本：**
  - 股權成本  (Ke) = 無風險利率 (Rf) + β × 市場風險溢價 (Rm − Rf) + 規模溢價

  - 假設市區風險溢價 = 5.55％
  - 無風險利率 = 2.5％ (估算)

- **债务成本（税后） = （利息支出 / 总债务）×（1 - 税率）:**
  - 假設稅率 = 21% 
  - 總債務 = $94,478,999,552

- **資本權重：**
  - 股權權重 (E/V) = 市值 / (市值 + 總債務)：$5,214,146,920,448 / ($5,214,146,920,448 + $94,478,999,552)
  - 債務權重 (D/V) = 總債務 / (市值 + 總債務 )：$94,478,999,552 / ($5,214,146,920,448 + $94,478,999,552)

### WACC 計算
- Ke = Rf + β × (Rm - Rf)
- Kd = (利息支出 / 總債務) × (1 - 稅率)
- WACC = (Ke × E/V) + (Kd × D/V)

最終計算出來的WACC約為7.5%。
