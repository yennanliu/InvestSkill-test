折現現金流（DCF）模型被認為是內在價值估算的金標準。透過未來現金流分析，DCF模型能夠確定企業的真實價值，而不受市場情緒或同業定價的影響。本報告旨在透過DCF方法對蘋果公司（AAPL）進行詳細的價值估算，包括10年現金流預測、加權平均資本成本（WACC）詳細分解、敏感性分析及三種情境的機率加權價值。

## 一步一步地進行DCF估值

### 第1步：設立基準指標

- **過去12個月自由現金流（TTM FCF）** = 營運現金流－資本支出
- **營收基礎**（TTM營收和最近完整財年）
- **自由現金流比率（FCF margin）**= FCF / 營收 × 100%
- **流通股數（稀釋後）**：包含員工股權激勵（SBC）的調整
- **淨債務** = 總債務 − 現金及等價物（若為負值表示淨現金）
- **員工股權激勵（SBC）**：若SBC尚未扣除，從自由現金流中扣除此項成本
- **有效稅率**（TTM基礎，去除一次性稅務事件）

### 第2步：營收成長預測（第1-10年）

- **分部預測**：若可能，分別預測各營收部門
- **歷史成長分析**：3年、5年、10年CAGR作為基準
- **分析師共識估計**：第1-3年的賣方共識估計作為交叉檢查
- **管理層展望**：未來營收指引及長期目標
- **行業成長率**：作為成長上限
- **成長減速**：前5年較高，後5年趨向終端成長率
- **三種情境**：樂觀（市場份額增長、利潤擴大）、基本（歷史趨勢）、悲觀（競爭壓力、宏觀逆風）

### 第3步：自由現金流比率假設

- **歷史自由現金流比率趨勢**（擴張或穩定或壓縮）
- **經營槓桿潛力**：固定成本隨營收擴大而被槓桿化？
- **資本支出密度**（占營收比）：增加或減少？
- **營運資金變化**：是消耗者還是產生者？
- **SBC調整**：從報告的營運現金流中扣除SBC來獲得真實經濟FCF

### 第4步：終端價值計算

- **終端成長率（g）**：2–3%（與名義GDP增長掛鉤）。切勿設定g > WACC
- **戈登成長模型（首選）**：
  ```
  TV = FCF₁₀ × (1 + g) / (WACC − g)
  ```

### 第5步：WACC計算

**股本成本 (CAPM)**:
```
Ke = Rf + β × (Rm − Rf)
```
- Rf = 無風險利率（目前10年期美國國債收益率）
- β = 股票貝塔（5年每月）
- Rm − Rf = 股權風險溢酬

**債務成本**：
```
Kd = (利息支出 / 總債務) × (1 − 有效稅率)
```

**資本結構權重**：
- E/V = 市值 / (市值 + 總債務)
- D/V = 總債務 / (市值 + 總債務)

**WACC公式**：
```
WACC = Ke × (E/V) + Kd × (D/V)
```

### 第6步：現金流折現

### 第8步：安全邊際評估

```

```

## 常見DCF陷阱

1. **不當假設**：過度推測未來成長率。
2. **終端價值過重**：如果終端價值超過企業價值的70%，需要仔細檢查終端假設。
3. **WACC過低**：忽視規模或流動性溢價。
4. **忽略周期性**：採用峰值FCF比率來估值周期性企業。
5. **忽視員工股權激勵**：SBC是實際成本。
6. **單一情境思考**：總是運行不同情境。
7. **營運資金和資本支出的隱藏變化**：快速成長的企業通常大量消耗營運資金。
8. **忽視匯率和地理混合**：國際業務時，需要運用適當折現率按地區預測。

## DCF相對估值對比

**DCF更可靠的時機**：
- 穩定、成熟，現金流可預測企業
- 資產輕型，現金流轉換率高的企業

**DCF不太可靠的時機**：
- 尚未有現金流正值的初創高增長企業
- 高度周期性企業，需用大量判斷力來調整現金流
- 金融企業
