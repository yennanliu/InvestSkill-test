# 蘋果公司 (Apple Inc.) 折現現金流 (DCF) 評值報告

## 總覽

折現現金流 (DCF) 是估算企業內在價值的黃金標準，能夠回答「這家企業基於未來所產生的現金流值多少錢？」這個根本性問題。不同於相對估值，DCF 提供企業真正的絕對價值，而不受市場情緒或同業組合定價的影響。

## DCF 步驟與方法論

### 第一步：建立基礎指標

收集並記錄當前基準以供後續預測：

- **追蹤十二個月自由現金流 (TTM FCF)：** 營運現金流 − 資本支出
- **營收基礎**（TTM 營收和最近完整財年）
- **自由現金流利潤率 (FCF Margin)：** TTM FCF / TTM 營收 × 100%
- **流通股數**（稀釋後 ─ 包括尚未歸屬的受限制股票單位和選擇權作為股權薪酬調整）
- **淨債務：** 總債務 − 現金及等同物（負數淨債務即為現金餘額狀況）
- **股權薪酬 (SBC)：** 確認為真實的稀釋成本；若尚未排除，自 FCF 中扣除
- **實際稅率：** 以 TTM 為基礎，且去除一次性稅務事件

### 第二步：營收成長預測（第 1 至 10 年）

使用多種指標來確立合理的成長假設：

- **多部門分析 (Segment approach)：** 當可能時，分部預測各營收部門
- **歷史成長分析：** 3年、5年與10年營收複合成長率作為基準
- **分析師一致預期：** 使用賣方分析師預期（第 1-3 年）作為交叉檢查
- **管理層指引：** 前向營收指引與長期目標
- **行業成長率：** 作為最高錨點
- **成長趨緩：** 第 1-5 年較高成長；第 6-10 年逐漸接近終端成長率
- **三種情境：** 牛市（市場份額增長、利潤率升高），基礎（歷史趨勢），熊市（競爭壓力、宏觀困境）

### 第三步：自由現金流利潤率(FCC Margin) 假設

基於經營槓桿和商業模式動力預測未來 FCF 利潤率：

- **歷史 FCF 利潤趨勢：** 擴張、穩定或縮小
- **經營槓桿可能性：** 作為營收擴展的固定成本何時被有效利用？
- **資本支出強度 (% of revenue)：** 增加或減少？
- **營運資本變化：** 消耗或產生？
- **去除一次性項目影響**：刪除訴訟結算和重組費用
- **SBC 調整**：從報告的營運現金流中扣除 SBC，以獲取真正的經濟 FCF

### 第四步：終端價值計算

終端價值代表所有10年顯性預測期以後的現金流的現值：

- **終端成長率 (g) ：** 通常為 2-3%（定位於國內生產總值名義成長）。切勿設g > 加權平均資本成本 (WACC)，這意味著無限價值
- **戈登成長模型 (首選)：**
  ```
  TV = FCF₁₀ × (1 + g) / (WACC − g)
  ```
- **退出倍數法 (替代方法)：**
  ```
  TV = FCFₙ × (EV / FCF exit multiple)
  ```
- **終端價值佔企業價值百分比：** 若 TV > 80% 總 EV，須明確標記並擴大敏感度範圍

### 第五步：WACC 計算

**股權成本 (CAPM)：**
```
Ke = Rf + β × (Rm − Rf)
```
- Rf = 無風險利率（當前美國 10 年期國債收益率）
- β = 股票貝塔（5 年每月）
- Rm − Rf = 股權風險溢酬（使用 Damodaran 當前 ERP，歷史上約為 5–6%）
- 規模溢價：小型/中型公司增加 0.5–2%

**負債成本：**
```
Kd = (Interest Expense / Total Debt) × (1 − Effective Tax Rate)
```

**資本結構權重**（使用市場價值權重，而非賬面價值）：
- E/V = 市值總股本 / (市值總股本 + 總債務)
- D/V = 總債務 / (市值總股本 + 總債務)

**加權平均資本成本公式：**
```
WACC = Ke × (E/V) + Kd × (D/V)
```

**風險類型的典型 WACC 範圍：**
```
風險類型         WACC 範圍       例子
────────────────────────────────────
低風險 (公用事業) 6–8%           受監管的公用事業、大型消費品
中等風險         8–11%          大型科技股、成熟成長企業
高風險           11–15%         小型股、發展中市場、週期性企業
極高風險         15–20%+        初創、高危、未有收益的企業
```

## 常見 DCF 陷阱

1. **垃圾進, 垃圾出：** 過度外推近期高成長率。特別保守地評估第 6-10 年。
2. **終端價值支配：** 若終端價值佔企業價值 > 70%，請嚴格測試終端假設。
3. **WACC 過低：** 忽視小型公司規模流動性溢價，會人為抬高內在價值。
4. **忽視週期性：** 對週期性企業使用峰值 FCF 邊際。始終透過完整商業循環去標準化 FCF。
5. **忽視股權薪酬：** SBC 是一個真實稀釋成本。從營運現金流中減去。
6. **單一情境思考：** 永遠運行牛市、基礎與熊市情境。
7. **隱藏的營運資本和資本支出變動：** 快速增長公司經常消耗大量營運資本。
8. **匯率與地理構成：** 對於跨國企業，以地理為單位進行預測，並使用適當折扣率。

## DCF vs. 相對估值

**何時 DCF 最可靠：**
- 穩定、成熟業務，具預測和一致的 FCF
- 輕資產業務，具有高 FCF 轉換（如軟件、消費品牌）
- 有 10 年以上 FCF 生成歷史的公司

**何時 DCF 不太可靠：**
- 未有正 FCF 的早期成長公司
- 正常化 FCF 需要顯著判斷的強週期性企業
- 金融公司（銀行、保險、REITs）— 使用市價/賬面價、盈測率、市盈率等
- 逆轉情況下盈利路徑不確定的公司
