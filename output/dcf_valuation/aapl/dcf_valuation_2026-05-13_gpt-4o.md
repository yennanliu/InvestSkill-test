## 概要

折現現金流量（DCF）分析被視為股權內在價值估計的黃金標準。此分析方法旨在通過估算公司未來可產生的現金流量來回答「這家公司的實際價值是多少？」這一基本問題。與相對估值不同，DCF 分析基於絕對標準評估公司價值，不受市場情緒或同行定價影響。因此，DCF 需要嚴謹的數據假設，小幅度的假設變化會在10年內產生顯著影響。因此，建議建模三種情境（牛市/基礎/熊市）並提供敏感性分析表，以避免將假設呈現為單點預估。

## DCF 推算步驟

### 步驟 1：建立基礎指標

在預測內容之前，收集並記錄當前基準數據：

- **隨季流動年（TTM）自由現金流** = 營運現金流量 − 資本支出
- **營收基礎**（TTM 營收和最近一個完整會計年度）
- **FCF 利潤率**（TTM FCF / TTM 營收 × 100%）
- **已發行股票數量**（稀釋後 — 包括未行使的股票期權和股權激勵）
- **淨債務** = 總債務 − 現金及等價現金（負淨債務 = 淨現金位置）
- **股票基礎補償（SBC）** — 確認為真正的稀釋成本；如果未已扣除，則從 FCF 中扣除
- **有效稅率**（TTM 基礎，需對一次性稅務事件進行非正常化處理）

### 步驟 2：營收成長預測（第 1–10 年）

使用多個錨來三角化可信的成長假設：

- **分部分析**：在可能的情況下，分別預測每個收入部門
- **歷史成長分析**：以3年、5年和10年營收複合年增長率作為基準
- **分析師一致預測**：採用賣方一致預測1–3年作為對照
- **管理層指引**：前瞻性營收指引和長期目標
- **行業成長率**：視為上限錨
- **成長遞減**：第一到五年使用較高成長，第六至十年緩慢增至終端成長率
- **三種情境**：牛（市場份額增長，利潤擴展），基礎（歷史趨勢），熊（競爭壓力，宏觀逆風）

### 步驟 3：FCF 利潤率假設

根據經營槓桿和商業模式動態預測未來 FCF 利潤率：

- **歷史 FCF 利潤率趨勢**（擴展、穩定或壓縮）
- **營運槓桿潛力**：隨著營收增長，哪些固定成本在被利用？
- **資本支出強度**（佔營收比重）：增長或減少？
- **營運資本變化**：消耗還是產生？
- **剔除一次性項目**：如訴訟賠償、重組費用
- **SBC 調整**：從報告的經營現金流中扣除 SBC 獲得真實經濟 FCF

### 步驟 4：終端價值計算

終端價值代表10年規劃期之外的所有現金流：

- **終端成長率 (g)**：通常為2–3%（參照名義 GDP 增長），永遠不要將 g 設為大於 WACC，這表示無限價值
- **戈登增長模型（偏好）**：
  ```
  TV = FCF₁₀ × (1 + g) / (WACC − g)
  ```
- **退出倍數法（替代）**：
  ```
  TV = FCFₙ × (EV / FCF exit multiple)
  ```
- **終端價值占企業價值的百分比**：若TV > 80% 的總 EV，則明顯標示並擴展敏感性範圍

### 步驟 5：WACC 計算

**股權成本（資本資產定價模型，CAPM）**：
```
Ke = Rf + β × (Rm − Rf)
```
- Rf = 無風險利率（當前 10 年美國國債收益率）
- β = 股票風險值（5 年月度）
- Rm − Rf = 股權風險溢價（使用 Damodaran 當前 ERP，歷史上為 5–6%）
- 小型股風險溢價：對小/中型股加 0.5–2%

**債務成本**：
```
Kd = (利息費用 / 總債務) × (1 − 有效稅率)
```

**資本結構權重**（使用市值權重，而非賬面價值）：
- E/V = 股權市值 / (股權市值 + 總債務)
- D/V = 總債務 / (股權市值 + 總債務)

**WACC 公式**：
```
WACC = Ke × (E/V) + Kd × (D/V)
```

**按風險特徵的典型 WACC 範圍**：
```
風險特徵       WACC 範圍   公司範例
─────────────────────────────────────────────────────
低風險（公用事業） 6–8%     受管制的公用事業，大型消費品公司
中風險          8–11%   大型科技公司，成熟的成長型企業
高風險          11–15%  小型股、新興市場、週期性公司
極高風險         15–20%+ 初創公司、財務困難、尚無收入
```

## 常見的DCF陷阱

1. **無用輸入，無用輸出**：將最近的高增長率過度外推到未來十年。尤其是在第6至10年要謹慎。
2. **終端價值主導**：若TV > 70%的企業價值，則需要積極壓力測試終端假設。
3. **WACC 過低**：忽略小企業的規模/流動性溢價會人為提升內在價值。
4. **忽視週期性**：對週期性公司使用峰值現金流利潤率。永遠通過完整的商業週期對現金流進行非正常化。
5. **忽略股票基礎補償**：股票基礎補償是一個真實的稀釋成本。從經營現金流中扣除。
6. **單一情境思維**：永遠運行牛市、基礎和熊市情境。
7. **隱性營運資本和資本支出變化**：快速增長的公司通常會消耗大量營運資本。
8. **貨幣和地理混合**：對於國際業務，按地理區域進行預測並使用適當的折現率。

## DCF 與相對估值的比較

**當 DCF 最可靠**：
- 穩定、成熟企業，擁有可預測、一致的自由現金流
- 資產輕型公司，高現金流轉換率（軟體、消費品牌）
- 具有 10 多年自由現金流生成歷史的公司

**當 DCF 不太可靠**：
- 初創成長公司，尚無正現金流
- 高度週期性公司，需大量判斷來非正常化現金流
- 金融公司（銀行、保險、REITs）— 使用市績/賬面、P/E 或股利折現模型
- 處於轉型中的情況，盈利途徑不確定
