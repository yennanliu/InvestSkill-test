### 第五步：加權平均資本成本（WACC）計算

- **成本模型 (CAPM)**:
  ```
  Ke = Rf + β × (Rm − Rf)
  ```
  - Rf = 無風險收益率（當前10年美國國債收益率）
  - β = 股票貝塔值（五年每月）
  - Rm − Rf = 股權風險溢價
  - 規模溢價：對小型/中型公司增加0.5-2%

- **負債成本**：
  ```
  Kd = (利息支出 / 總負債) × (1 - 有效稅率)
  ```

- **資本結構權重**:
  - E/V = 股本市值 / （股本市值 + 總負債）
  - D/V = 總負債 / （股本市值 + 總負債）

- **WACC 公式**：
  ```
  WACC = Ke × (E/V) + Kd × (D/V)
  ```
