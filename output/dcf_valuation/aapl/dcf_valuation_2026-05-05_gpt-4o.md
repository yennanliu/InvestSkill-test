### 第五步：WACC 計算

**股本成本 (CAPM)**：
```
Ke = Rf + β × (Rm − Rf)
```
- Rf = 無風險利率（當前10年美國國債收益率）
- β = 股票貝塔係數（5年每月）
- Rm − Rf = 股權風險溢價

**債務成本**：
```
Kd = (利息費用 / 總債務) × (1 − 有效稅率)
```

**資本結構權重**：
- E/V = 市值 / (市值 + 總債務)
- D/V = 總債務 / (市值 + 總債務)

**加權平均資本成本 (WACC) 公式**：
```
WACC = Ke × (E/V) + Kd × (D/V)
```

## 常見DCF錯誤

1. **輸入愚蠢資料導致愚蠢結果**：切忌盲目外推高增長率。
2. **終值主導企業價值**：若終值占比>70%，需嚴格檢查其假設。
3. **WACC過低**：忽略小公司的額外風險溢價。
4. **忽視周期性**：避免採用高峰時期的現金流評估。
5. **忽視股份補償費用**：應從營運現金流中扣減。
6. **單一場景假設**：試試多種假設場景。
7. **忽視營運資金及資本支出變化**。
8. **忽略貨幣及地域因素**。

## DCF與相對估值的比較

**DCF優勢用於以下情況**：
- 穩定和成熟的公司
- 資產輕量化的行業

**DCF劣勢用於以下情況**：
- 初創未盈利公司
- 高度週期性的公司
- 金融類公司
