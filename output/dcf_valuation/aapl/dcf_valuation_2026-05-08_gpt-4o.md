# 蘋果公司（AAPL）折現現金流估值報告

## 總覽

折現現金流模型（DCF）是一種用於估算公司內在價值的黃金標準方法。它旨在回答一個基本問題：「基於公司的未來現金流量，該公司的價值是多少？」這種方法獨立於市場情緒和同行估值，提供公司的絕對價值評估。

DCF需要嚴謹的假設。即使是增長率、利潤率或貼現率的細微變化，經過10年的時間累積，也會對估值結果產生重大影響。因此，建議進行三種情境（牛市/基準/熊市）的模擬，並提供敏感性分析表，以確保假設不僅僅是點估計。

## 折現現金流的詳細步驟

### 步驟1：建立基礎指標

在進一步預測之前，先收集並記錄當前基線：

- **過去十二個月（TTM）自由現金流（FCF）** = 營業現金流 − 資本支出
- **收入基礎**（TTM收入和最近一個完整財年）
- **FCF邊際**（TTM FCF / TTM收入 × 100%）
- **流通在外股票**（完全稀釋後 — 包括未歸屬限制性股票單位和選擇權）
- **淨負債** = 總負債 − 現金及現金等價物（負淨負債 = 淨現金狀況）
- **股票基礎薪酬（SBC）** — 鑑別作為實際稀釋成本；如未排除，從FCF中減去
- **有效稅率**（基於TTM，排除一次性稅務事件）

### 步驟2：收入增長預測（1至10年）

運用多種參照來構建合理的增長假設：

- **分部法**：採用分部預測，從而更精確地評估增長
- **歷史增長分析**：使用3年，5年及10年收入年均成長率作為基準參照
- **分析師共識估計**：使用賣方共識作為1-3年的交叉檢查
- **管理層指引**：包括收入指引及長期目標
- **行業增長率**：用作最高增長率的參考
- **增長趨勢**：年1-5年設定較高增長，並在年6-10年放緩至終端增長率
- **三種情景**：牛市（市場份額增加，利潤率擴大），基準（歷史趨勢），熊市（競爭壓力，宏觀經濟逆風）

### 步驟3：FCF邊際假設

根據業務模式和操作槓桿預測未來FCF邊際：

- **歷史FCF邊際訓練**（擴展、穩定或收縮）
- **操作槓桿潛力**：隨著收入增長，什麼固定成本可以被槓桿化？
- **資本支出強度**（以百分比計的收入）：是否在增加或減少？
- **營運資本變動**：是消耗資金還是產生資金？
- **排除一次項目**：剝離訴訟結算，重組費用
- **SBC調整**：從報告的營運現金流中減去SBC以獲得真實經濟FCF

### 步驟4：終端價值計算

終端價值代表超出10年顯式預測期的所有現金流：

- **終端增長率（g）**：通常為2-3%（與名目GDP增長率對齊）。切勿設定g > WACC，因這意味著無限價值
- **戈登增長模型（首選）**：
  ```
  TV = FCF₁₀ × (1 + g) / (WACC − g)
  ```
- **退出倍數法（替代方案）**：
  ```
  TV = FCFₙ × (EV / FCF退出倍數)
  ```
- **終端價值作為企業價值的百分比**：如果TV > 80% 總EV，則明確標示並擴展敏感範圍

### 步驟5：加權平均資金成本（WACC）計算

**股本成本（CAPM）**：
```
Ke = Rf + β × (Rm − Rf)
```
- Rf = 無風險利率（當前10年期美國國債收益率）
- β = 股票貝塔係數（5年月均）
- Rm − Rf = 股權風險溢價（使用Damodaran當前ERP，歷史值5-6%）
- 規模溢價：為小型/中型公司增加0.5–2%

**債務成本**：
```
Kd = (利息費用 / 總負債) × (1 − 有效稅率)
```

**資本結構權重**（使用市值權重，而非賬面價值）：
- E/V = 股本市值 /（股本市值 + 總負債）
- D/V = 總負債 /（股本市值 + 總負債）

**WACC公式**：
```
WACC = Ke × (E/V) + Kd × (D/V)
```

**按風險程度的典型WACC範圍**：
```
風險程度            WACC範圍      公司例子
──────────────────────────────────────────
低風險（公用事業）  6–8%          受監管的公用事業，大型消費品
中風險               8–11%         大型科技股，成熟成長公司
高風險               11–15%        小型股，新興市場，週期性行業
非常高風險           15–20%+       初創公司，困境公司，尚無收入
```

### 步驟6：現金流折現

```
第n年的FCF現值 = FCFₙ / (1 + WACC)ⁿ

終端價值現值 = TV / (1 + WACC)¹⁰

企業價值 = Σ PV(FCF年1–10) + PV(終端價值)

股本價值 = 企業價值 − 淨負債
  （如果公司具有淨現金狀態，則加回淨現金）

每股內在價值 = 股本價值 / 稀釋後流通股
```

理解指南：

- 如果無單元格顯示安全邊際→股票在所有合理情況下均顯示昂貴

### 步驟8：安全邊際評估

```
安全邊際 = (內在價值 − 市場價格) / 內在價值 × 100%

上升潛力 = (內在價值 − 市場價格) / 市場價格 × 100%
```

**評估尺度**：
```
安全邊際    評估
>30%折扣       吸引力 — 強安全邊際
10–30%折扣     公平價值 — 長期投資者的合理入場點
0–10%折扣      合理定價 — 安全邊際有限
10–30%溢價     略微昂貴 — 需要強烈的增長信心
>30%溢價       昂貴 — 需大幅增長證明價格合理
>50%溢價       非常昂貴 — 計入完美預期；高風險
```

## 常見DCF陷阱

1. **垃圾進垃圾出**：過度外推最近的高增長率。尤其是對6至10年的預測要保守。
2. **終端價值主導**：如果TV > 70% 企業價值，需對終端假設進行壓力測試。
3. **WACC過低**：忽視小公司規模/流動性溢價會人為高估內在價值。
4. **忽視周期性**：對於週期性較強的業務，使用峰值FCF邊際。始終需在完整經濟周期內進行FCF正常化。
5. **忽視股票基礎薪酬**：SBC是實際稀釋成本。從營運現金流中減去。
6. **單一情景思維**：始終運行牛市、基準、和熊市情景。
7. **隱藏的營運資金和資本支出變化**：快速增長的公司常常消耗大量營運資金。
8. **貨幣及地區組合**：對於國際公司，需要按地理位置預測，並使用適當的折現率。

## DCF對比相對估值

**當DCF最可靠時**：
- 穩定、成熟的企業，具有可預測性，且現金流一致
- 資產輕型業務，具有高FCF轉換率（例如軟件，消費品牌）
- 擁有10年以上FCF產生歷史的公司

**當DCF不太可靠時**：
- 早期增長公司沒有正FCF
- 高度周期性業務，需要大量判斷以正常化FCF
- 金融公司（如銀行、保險、REIT）— 使用市價/賬面、P/E或股息貼現模型
- 欲轉虧為盈但前景不確定的情況
