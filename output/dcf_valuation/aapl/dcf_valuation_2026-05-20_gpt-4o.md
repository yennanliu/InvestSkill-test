## 步驟4：終值計算

### 計算方法
- 終值增長率（g）：一般設置在2–3%，不大於WACC
- 戈登增長模型：
  ```
  TV = FCF₁₀ × (1 + g) / (WACC − g)
  ```
- 終值占企業價值的百分比：過高時請審慎處理

---

## 步驟5：加權平均資本成本（WACC）

### 計算基礎
- 股權成本（CAPM）
  ```
  Ke = Rf + β × (Rm − Rf)
  ```
  - Rf = 無風險利率（當前10年美國國債收益率）
  - β = 股票Beta值（五年每月）
  - Rm − Rf = 股權風險溢酬

### 資本結構權重
- 以市值計算權重
- 市值加總

### WACC:
  ```
  WACC = Ke × (E/V) + Kd × (D/V)
  ```

## 步驟6：現金流量折現

```
PV of Year n FCF = FCFₙ / (1 + WACC)ⁿ
PV of Terminal Value = TV / (1 + WACC)¹⁰
企業價值 = Σ 現金流量的折現值 (FCF years 1–10) + 終值折現值
股權價值 = 企業價值 − 淨負債
每股內在價值 = 股權價值 / 稀釋後已發行股數
```
