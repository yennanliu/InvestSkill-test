## 概述

折現現金流 (DCF) 模型是估算內在價值的金標準。它主要回答一個問題：「基於公司未來產生的現金流，這家公司到底值多少？」這與市場情緒或同業定價無關，是一種絕對估值方法。

### 第二步：營收增長預測（1–10年）

採用不同的模型來就增長假設建立辯護基礎：

### 第三步：自由現金流利潤率假設

基於運營槓桿和商業模式動態預測未來的自由現金流利潤率：

- 歷史趨勢是否在擴展、穩定或壓縮

### 第四步：終值計算

- **終值增長率 (g)**: 普遍設定為 2–3%。

Gordon Growth Model 用於計算終值：
```
TV = FCF₁₀ × (1 + g) / (WACC − g)
```

### 第五步：WACC 計算

**股權成本 (CAPM)**:
```
Ke = Rf + β × (Rm − Rf)
```

- **無風險利率 Rf**: 現行美國 10 年期國債收益
- **Beta 值 𝛽**: 1.065
- **股權風險溢酬 (Rm − Rf)**: 通常使用 Damodaran 當前溢酬

**負債成本**:
```
Kd = (金融負債費用 / 總負債) × (1 − 實際稅率)
```

**資本結構權重**:
```
WACC = Ke × (E/V) + Kd × (D/V)
```
其中，E/V 和 D/V 為市值權重。

### 第六步：現金流折現

```
PV of Year n FCF = FCFₙ / (1 + WACC)ⁿ
PV of Terminal Value = TV / (1 + WACC)¹⁰
```

### 第七步：敏感分析

提供 5x5 敏感性表格，顯示在不同的 WACC 和終值增長率組合下的內在價值。

### 第八步：安全邊際評估

```
Margin of Safety = (Intrinsic Value − Market Price) / Intrinsic Value × 100%
```
