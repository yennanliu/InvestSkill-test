## 詳細DCF分析步驟

### 第一階段：建立基礎數據

- **12個月遞延自由現金流（TTM FCF）**：操作性現金流減資本支出
- **營收基礎**：（TTM營收及最近一完整會計年度）
- **FCF邊際率**：TTM FCF/TTM營收 × 100%
- **稀釋後流通在外股數**（需包括未賦予RSU及期權的SBC調整）
- **淨負債**：總債務減現金與現金等價物（負淨負債表示淨現金部位）
- **股份基礎補償（SBC）**—視作為真實稀釋成本；若尚未扣除則需從FCF中減去
- **實際稅率**：（TTM基礎，對單筆稅務事件正常化）

### 第二階段：營收增長預測（第1年至第10年）

- **分部法**：若可能，分別預測每個營收部門
- **歷史增長分析**：以3年、5年、10年營收複合增長率為基礎
- **分析師共識估計**：以賣方共識作為第1年至第3年的對照
- **管理層指引**：前瞻營收指導及長期目標
- **行業增長率**：用作上限
- **增長趨緩**：第1年至第5年較高增長，第6年至第10年逐漸放緩至終端增長率
- **三種情境**：牛市（市場份額增加，邊際擴張）、基準市（歷史趨勢）、熊市（競爭壓力、宏觀逆風）

### 第三階段：FCF邊際假設

- **歷史FCF邊際趨勢**（擴張、穩定或壓縮）
- **操作槓桿潛力**：在收入擴大之下有哪些固定成本可被槓桿化？
- **資本支出強度**（佔營收百分比）：增加還是減少？
- **營運資本變化**：消費者或生成者？
- **一時性項目正常化**：剔除訴訟和重整費用
- **SBC調整**：扣除SBC從報告操作性現金流以獲取實際經濟FCF

### 第四階段：終端價值計算

終端價值表示第11年以後所有的現金流價值：

- **終端增長率（g）**：通常為2-3%（錨定於名目GDP增長）；切勿設定g>WACC以避免無窮價值
- **戈登增長模型（優選）**：
  ```
  TV = FCF₁₀ × (1 + g) / (WACC − g)
  ```
- **退出多重法（備選）**：
  ```
  TV = FCFₙ × (EV / FCF退出多重)
  ```
- **終端價值佔企業價值百分比**：若TV > 80%的整體EV，需明確註明並拓寬敏感範圍

### 第五階段：計算加權平均資本成本（WACC）

**股本成本（CAPM）**：
```
Ke = Rf + β × (Rm − Rf)
```
- Rf = 無風險利率（當前10年期美國國債收益率）
- β = 股票貝塔值（5年每月）
- Rm − Rf = 股本風險溢價（使用Damodaran的當前ERP，歷史為5-6%）
- 尺寸溢價：對於中小型公司，添加0.5–2%

**債務成本**：
```
Kd = (利息費用 / 總債務) × (1 − 實際稅率)
```

**資本結構權重**（使用市場價值權重，而非賬面價值）：
- E/V = 股票市值 / (股票市值 + 總債務)
- D/V = 總債務 / (股票市值 + 總債務)

**WACC公式**：
```
WACC = Ke × (E/V) + Kd × (D/V)
```

### 第六階段：折現現金流

```
年 n FCF 的現值 = FCFₙ / (1 + WACC)ⁿ

終端價值現值 = TV / (1 + WACC)¹⁰

企業價值 = Σ 現值(FCF 年 1–10) ＋ 終端價值現值

股權價值 = 企業價值 − 淨負債
  (若公司有淨現金部位則添加回淨現金)

每股內在價值 = 股權價值 / 稀釋後流通股數
```

## 常見DCF陷阱

1. **垃圾進垃圾出**：延伸近年高增長率過於未來。需於第6-10年特別保守。
2. **終端價值占據主導**：若TV > 70%企業價值，需激進地壓力測試終端假設。
3. **WACC過低**：對於小公司忽略了尺寸/流動性溢價，進而虛增內在價值。
4. **忽視周期性**：對周期性業務使用峰值FCF邊際。必須通過完整商業周期來正常化FCF。
5. **忽視股份基礎補償**：SBC為真實稀釋成本。應從運營現金流中扣除。
6. **單一情境思維**：務必運行牛市、基準市和熊市情境。
7. **隱藏工作資本和資本支出變化**：快速增長的公司通常會消耗大量工作資本。
8. **貨幣與地理組合**：對於國際業務，應以地理做預測並適用合適折扣率。

## DCF vs. 相對估值

**當DCF最為可靠**:
- 穩定、成熟且現金流可預期的企業
- 資產輕的業務，高現金流轉化率（如軟件、消費品牌）
- 有10年以上現金流生成歷史的公司

**當DCF較不可靠**:
- 尚未產生正現金流的初期成長公司
- 需要顯著判斷來正常化現金流的高度週期性業務
- 金融公司（如銀行、保險、REITs）— 使用價格 / 賬面、價格 / 收益或股息折現模型
- 轉型情境中，通往盈利的路徑不確定
