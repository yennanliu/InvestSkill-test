How it works

Four steps, no infrastructure.

The whole thing is a Python package and a handful of GitHub Actions workflows. Trigger one by hand, or let the weekday schedule do it.

Load the frameworks

The workflow clones yennanliu/InvestSkill so GEMINI.md becomes the system context and prompts/*.md supply the frameworks.

Snapshot the market

One yfinance fetch per run — price history, financials, and valuation inputs — shared across every module so the numbers can't drift mid-report.

Run the modules

Each framework goes to the model with the shared snapshot. Gemini 3.6 Flash by default; --provider openai or claude swaps it.

Commit the report

Markdown is written to output/<type>/<ticker>/, Mermaid charts are linted, and the bot commits it back to main.
