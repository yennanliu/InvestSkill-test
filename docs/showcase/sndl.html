1個股評估stock-eval

SNDL 在本展示櫃中的角色是方法論對照組： 如果一套評分框架只在半導體成長股上有效，那它不是分析框架，而是主題偏好。

它的商業模式與其他三檔沒有任何共同點：加拿大大麻零售與生產、加上酒類零售通路。 沒有 AI 曝險、Beta 僅 0.92（其他三檔均超過 2.0）、 毛利率 27.2%（記憶體廠為 68%–73%）、營收成長為負。

而框架給出的結果值得注意：SNDL 的品質維度得 7.3 分，與 MRVL 完全相同。 一家 ROIC −0.3%、營收衰退的公司，與一家營收成長 27.6% 的 AI 晶片設計商， 在品質維度上同分。這不是框架失效，而是它正確地捕捉到了兩件事： SNDL 的 Piotroski 7／9（趨勢改善）與極低負債（D/E 0.15） 確實構成了某種「品質」，而 MRVL 的 ROIC −8.4pp 價差同樣拖累了它的品質分。

但它也暴露了框架的限制：Piotroski F-Score 衡量的是「變好」，不是「好」。 一家從很糟變成不太糟的公司，可以拿到與穩定優質公司相同的分數。 這一點在解讀 SNDL 的 7／9 時必須明示——詳見下方基本面章節。

2競爭護城河competitor-analysis

Porter 五力

  • 現有競爭者（極高壓力）——加拿大大麻市場自 2018 年合法化後長期供過於求， 數十家生產商競逐同一批消費者，價格戰持續多年。毛利率 27.2% 即是這個結構的結果。
  • 新進者（高壓力）——零售端進入門檻低（取得執照即可開店）。
  • 供應商議價力（低）——SNDL 垂直整合（自有生產＋零售）， 且上游原料（大麻）本身是供過於求的商品。這是它唯一佔優勢的一力。
  • 客戶議價力（高）——終端消費者轉換成本為零，品牌忠誠度低， 且合法市場仍與非法市場競價。
  • 替代品（高）——酒類、其他娛樂性消費品。 SNDL 自身經營酒類零售，某種程度上是對這個替代威脅的對沖。

護城河評等：無（★☆☆☆☆），四檔中最低。 五力中四項為高或極高壓力。ROIC −0.3% 與此一致。

3基本面分析fundamental-analysis

SNDL 的財報必須從「這家公司在變好還是變壞」這個問題出發，而答案取決於用什麼尺度看。

年度尺度：明確改善。營業利益率 −8.6% → −11.0% → −3.6% → −0.5%； 營運現金流 −$6.7M → −$16.6M → +$54.9M → +$70.9M； 自由現金流 −$17.6M → −$24.6M → +$43.9M → +$58.1M。 毛利率 26.1% → 27.3%。Piotroski 7／9。

季度尺度：只是在零附近震盪。營業利益五季序列 +$2.9M → −$9.4M → +$10.3M → −$11.2M → −$5.4M。 正負交替，沒有任何兩個連續季度同向。 營收 $245M → $244M → $252M → $196M → $236M，2026 Q1 大幅下滑後僅部分回升。

⚠ Piotroski 7／9 為什麼會誤導

SNDL 的 7 分中，有 3 分來自「比去年進步」類型的檢定（ROA 上升、毛利率上升、資產周轉率上升）， 而它的基期是 ROA −7.0%。從 −7.0% 改善到 −1.2% 拿到滿分， 但 −1.2% 的 ROA 本身仍是虧損。

未通過的兩項恰好是絕對水準檢定：ROA > 0（−1.2%，未通過）與長期負債比下降 （11.3% → 12.7%，上升，未通過）。

對照 MU 的 9／9：MU 同時通過了改善類與絕對水準類的全部檢定。 同一個分數在不同基期上的意義完全不同，這是使用 F-Score 時必須揭露的限制。

盈餘品質：良好。TTM 營運現金流 $66.6M 對淨利 −$11.0M—— 現金流顯著優於帳面獲利，差異主要來自折舊與減值等非現金費用。 在虧損公司中，這是相對健康的形態（虧損來自帳面費用而非現金流出）。

⚠ 這個 DCF 的方法論限制（必讀）

對資本密集的循環股而言，以自由現金流為基礎的 DCF 有系統性偏誤： 在循環頂點，公司同時擁有最高的營運現金流與最高的資本支出， 使自由現金流被壓縮到遠低於盈餘能力的水準。

因此本報告不以 DCF 為主要估值依據，而在下一個模組以常態化盈餘法與相對倍數法交叉驗證。 三種方法的分歧程度本身，就是估值不確定性的度量。

6內部人交易insider-trading

SNDL 的 Form 4 申報中沒有任何個人內部人交易—— 15 筆申報全部來自發行人（Issuer）本身，性質為股票買回與註銷。

這在解讀上有兩層意義：

  • 正面：公司在股價 $1.36–$1.43（低於淨值 70%）處持續買回， 是資本配置的正確選擇。買回節奏為逐個交易日 （6 月 19、22、23、24、25、26、29、30 日連續申報），顯示這是系統性計畫而非機會性操作。
  • 缺口：沒有任何高管或董事的個人買進。 在一檔管理層公開認為便宜到值得動用公司資金買回的股票上， 個人層面零買進是一個值得注意的沉默。 本報告不將此解讀為負面訊號（可能受交易窗口限制），但記為資料缺口。

投資論點

SNDL 是加拿大最大的私營大麻零售商與生產商，同時經營酒類零售。 它與本籃子其他三檔毫無關聯——這正是它被納入的原因：作為對照組， 測試同一套評分框架在一個完全不同的商業與估值情境下是否仍然有效。

數字面的價值論述相當強：市值 $317.6M 對股東權益 $1.064B（股價淨值比 0.30）， 帳上現金 $183.2M、淨現金 $45.5M，流動比 4.84，P/S 僅 0.34， TTM 自由現金流為正 $33.0M，且公司正在每個交易日買回股票（6 月間逐日申報， 成交價 $1.36–$1.43）。股價 $1.22 就在 52 週最低點 $1.21 之上一美分。

但把股東權益排成一列，論述就變了：年度序列 $1.306B → $1.212B → $1.133B → $1.101B（四年侵蝕 16%、年均約 −$68M ≈ −5.3%）， 而最近兩季 $1.101B → $1.088B → $1.064B—— 半年減少 $37.5M，年化 −$75M ≈ −7.1%。侵蝕正在加速。 同期營業利益率 −8.6% → −11.0% → −3.6% → −0.5%，確實在改善， 但始終為負；ROIC −0.3% 低於 WACC 7.1%。 最近兩季更由小幅獲利轉回虧損（−$9.9M、−$7.8M）。 這使 SNDL 成為價值陷阱的標準形態：折價是真的，但分母在縮小， 折價會隨時間自行消失，而非靠股價上漲收斂。
