  • 淨利與現金流嚴重背離：儘管 2026 年淨利表面上成長至 1,337.5 億美元，但 FCF 卻由 2024 Peak 的 740.7 億美元逐年下滑至 2026 年的 669.9 億美元（TTM 數據因最新季度高額 Capex 扣除，甚至落至 165.5 億美元水位）。淨利成長已被資本密集度完全「掏空」。

2. 估值完美定價與折舊風暴 (Valuation Stretch & Earnings Quality)

  • 昂貴的營收倍數：目前的市售率（P/S）高達 11.59x，市價淨值比（P/B）高達 8.69x。在營收規模達 3,318 億美元的龐大基期下，要維持 11.6 倍的 P/S 需仰賴 Azure 超乎預期的加速成長。
  • 未爆彈：遞延折舊壓力：近三年累積投資超過 2,200 億美元於 Server 與 Data Center，這些資產將在未來 3-5 年內陸續進入折舊期。一旦營業成本（Cost of Revenue）中的折舊費用開始大量攤銷，目前 45.1% 的高營業利潤率將遭遇顯著逆風。

3. 資產負債表槓桿化與資本回報受限 (Capital Allocation & Balance Sheet Stress)

  • 淨現金轉為淨負債：微軟總負債已達 1,288.1 億美元，扣除 768.4 億美元現金後，淨負債達到 519.7 億美元（Debt/Equity 為 29.1%）。
  • 庫藏股能力受限：2026 年現金股利支出達 264.5 億美元，加上 1,159.5 億美元 Capex，已完全消耗掉 1,829.4 億美元的營運現金流（OCF）。這意味著微軟已無多餘的「自由現金」來進行大規模股票回購以支撐 EPS，過往靠減少股數推升 EPS 的金融工程槓桿已宣告失效。

4. AI 基礎設施商品化與客群集中風險 (Competitive & Secular Threats)

  • OpenAI 依賴度過高：微軟在 AI 領域的領先極度依賴對 OpenAI 的投資與算力綁定。若 OpenAI 轉向多雲架構（如擴大與 Oracle/AWS 合作）或自研晶片成功，微軟 Azure 的獨家溢價將快速消失。
  • 推論（Inference）成本高昂與價格戰：AI 算力出租（GPU-as-a-Service）逐漸商品化，面對 Google Cloud 與 AWS 的價格競爭，Azure 的 AI 營收毛利率遠低於傳統 SaaS 軟體（Office 365）。「營收結構向低毛利 AI 算力傾斜」將拉低整體毛利率（目前 67.9%）。
