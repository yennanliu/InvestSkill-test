1個股評估stock-eval

MRVL 在 AI 價值鏈中的位置，比 MU 或 SKHY 更難用一句話說清楚，而這正是它的機會與風險所在。

它做兩件事：客製化 ASIC（為特定客戶設計專屬的 AI 加速器， 替代通用 GPU）與光電互連（資料中心內外的高速傳輸）。 兩者都不是終端產品，而是被嵌進別人的系統裡——因此 MRVL 的營收高度依賴少數超大型客戶的設計選擇。

這帶來一個關鍵的不對稱：贏得一個設計案（design win）的營收能見度可達三到五年， 但輸掉一個設計案的損失同樣是三到五年，而且客戶通常不會提前告知。 相較於 MU 賣的是規格化商品（可以轉賣給別的客戶），MRVL 的產品一旦失去設計案就幾乎沒有殘值。

五季營收連續創高說明目前的設計案組合正在放量。但這也是為什麼 本報告把 MRVL 的護城河評為低於 MU—— 它的優勢繫於個別客戶關係，而非產業結構。

2競爭護城河competitor-analysis

Porter 五力

  • 現有競爭者（高壓力）——Broadcom（AVGO）是客製化 ASIC 的主導者， 規模與客戶關係都更深；此外還面對 NVIDIA 通用 GPU 的替代威脅 （若通用方案夠好，客戶就不需要客製化）。MRVL 是明確的挑戰者，不是領先者。
  • 新進者（中等壓力）——ASIC 設計門檻高，但雲端業者自研的趨勢 本身就是最危險的「新進者」：客戶可能變成競爭者。
  • 供應商議價力（高壓力）——依賴台積電先進製程與封裝配額。無自有產能。
  • 客戶議價力（極高壓力）——這是 MRVL 最弱的一環。 買方是少數超大型雲端業者，具備資源自研、也具備在多家 ASIC 供應商間比價的能力。 客戶集中度未在本資料中揭露，但產業結構決定它必然很高。
  • 替代品（高壓力）——通用 GPU 與客戶自研方案都是直接替代。

護城河評等：中等偏弱（★★☆☆☆），四檔中最低。 五力中有四項為高或極高壓力。ROIC 6.4% 低於 WACC 14.9% 的事實與這個評等一致—— 沒有護城河的公司無法長期賺取超額報酬，而 MRVL 的財務數字正是這樣呈現的。

3基本面分析fundamental-analysis

MRVL 的財報必須分兩層讀：營收層很好，獲利層很亂。

營收層。四個會計年度：$5.92B → $5.51B → $5.77B → $8.19B。 FY2026 跳增 42%，五季序列持續創高。毛利率 FY2023 50.5% → FY2026 51.0%，穩定。 研發支出 $1.78B → $2.08B，佔營收 25.4%。這一層沒有問題。

獲利層。GAAP 淨利四年：−$0.16B → −$0.93B → −$0.89B → +$2.67B。 四年中三年虧損。而 FY2026 的 $2.67B 淨利大於當年營業利益 $1.34B—— 淨利高於營業利益意味著存在大額非營業收益（處分利益或稅務項目），而非本業改善。

盈餘品質：需注意。TTM 營運現金流 $2.056B 對淨利 $2.527B，比率 0.81—— 低於 1.0，代表帳上獲利未完全轉為現金。這與 FY2026 淨利含一次性項目的判斷一致。 自由現金流 FY2026 $1.39B，與 FY2025 的 $1.39B 持平， 在營收成長 42% 的年度自由現金流零成長。

🚩 資產結構的集中風險

總資產 $22.29B，其中商譽 $11.06B（49.6%）。股東權益 $14.31B，商譽占 77.3%。 扣除商譽後有形股東權益約 $3.25B。四年間商譽由 $11.59B 微降至 $11.06B（僅小幅攤銷）， 未曾發生大額減損——這既可解讀為併購標的表現符合預期， 也可解讀為減損風險尚未被認列。存貨由 $1.03B 升至 $1.39B（+35%）， 略快於營收成長（+42% 則屬同步），需持續觀察。

⚠ 這個 DCF 的方法論限制（必讀）

對資本密集的循環股而言，以自由現金流為基礎的 DCF 有系統性偏誤： 在循環頂點，公司同時擁有最高的營運現金流與最高的資本支出， 使自由現金流被壓縮到遠低於盈餘能力的水準。 MRVL 的 TTM 自由現金流 $2.27B 僅為淨利 $2.53B 的 90%。

因此本報告不以 DCF 為主要估值依據，而在下一個模組以常態化盈餘法與相對倍數法交叉驗證。 三種方法的分歧程度本身，就是估值不確定性的度量。

8財報預期與分析師earnings-call-analysis

本報告未取得 MRVL 法說會逐字稿，故不做管理層語氣分析。 以下由共識預估與歷史實際值的對照推論市場預期。

8 月 28 日財報共識：EPS $0.927（區間 $0.88–$0.94）、 營收 $2.703B（區間 $2.600B–$2.761B）。相對最近一季實際的營收 $2.418B， 共識預期 +11.8% QoQ。

⚠ 共識 EPS $0.927 是哪一套基準？

最近一季 GAAP EPS 為 $0.04。共識 $0.927 是它的 23 倍。 而前瞻年度 EPS 共識為 $6.24——若以季度 $0.927 推算年度約 $3.71，與 $6.24 又不一致。

合理推斷：$0.927 為 non-GAAP 季度預估，$6.24 為 non-GAAP 年度預估但涵蓋不同期間， 或兩者的調整項目定義不同。本報告無法確認， 因此不以任何前瞻 EPS 為主要估值依據，並在 result-validator 中記為資料一致性缺陷。

EPS 預估區間極窄（$0.88–$0.94，離散度僅 1.07 倍），對照 MU 的 1.34 倍， 說明分析師對 non-GAAP 數字的可預測性有高度信心—— 這本身也印證了市場主要以 non-GAAP 追蹤這家公司。
