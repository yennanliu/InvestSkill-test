## 二、論點支柱 (Key Pillars)

### 支柱 1｜AWS 在 AI 週期中重新加速
- Q1'26 AWS +28%（15 季新高）、$150B 年化 run rate、營業利益率 37.7%、營業利益 $14.2B。
- AWS 是 AMZN 營業利益的主要來源（遠超其營收占比），是估值的核心引擎。AI 工作負載（訓練 + 推論）從試點走向持續計費消費，驅動增速與利潤率同步向上。

### 支柱 2｜自研晶片＝雲端毛利率的結構性上檔（最被低估）
- Graviton + Trainium + Nitro 已超 **$20B 年化 run rate**、三位數增長。
- 管理層明言：規模化後 Trainium 每年可省「數百億美元 capex」，並為推論帶來「**數百個基點的營業利益率優勢**」。
- 意義：這是垂直整合的護城河，讓 AWS 在 AI 推論時代相對 Azure/GCP（依賴外購 GPU）取得成本結構優勢——市場尚未充分定價此利潤槓桿。

### 支柱 3｜廣告：高毛利複利機
- Q1'26 廣告 +24% 至 $17.2B。零售媒體 + Prime Video 變現具高毛利、低邊際成本特性，是拉升合併利潤率的關鍵，且成長仍具韌性。

### 支柱 4｜零售利潤率拐點
- 北美零售利潤率創高，反映履約網絡區域化、機器人自動化的營運槓桿。零售正從「規模換份額」轉為「效率生利潤」。

### 支柱 5｜免費選擇權 (Optionality)
- **Anthropic 持股**：Q1 認列 $16.8B 稅前收益，揭示此策略投資的巨大隱含價值（同時綁定 AWS 的 AI 需求）。
- **Amazon Leo（低軌衛星）**：Q3 商業化，切入衛星寬頻長線市場。
- **機器人／自動化、醫療 (Amazon Pharmacy)、Kuiper 等**：市場多半未計入估值。

## 三、Sum-of-the-Parts (SOTP) — 為何「合併 P/E」會誤導

AMZN 是多引擎集團，用單一 P/E 估值會低估其分部價值。示意性 SOTP 框架（僅為方法示範，非精算）：

| 分部 | 估值方法（示意） | 說明 |
|---|---|---|
| **AWS** | 以獨立雲端業者的 EV/營業利益或 EV/Sales 倍數估值 | 高增速 + 37.7% 利潤率，理應享雲端溢價；為集團價值主體 |
| **廣告** | 對標高毛利數位廣告平台倍數 | 高毛利、雙位數成長，估值倍數應高於零售 |
| **北美 + 國際零售** | 以零售／電商倍數（EV/Sales 或 EV/EBIT） | 低倍數，但利潤率正在改善 |
| **自研晶片** | 尚未被獨立定價的「嵌入式半導體」價值 | 潛在的隱藏 upside |
| **選擇權（Anthropic/Leo/其他）** | 個別評估或計為淨資產 | Anthropic 收益已揭示部分價值 |

**核心洞見**：把 AWS + 廣告（高倍數、高毛利）與零售（低倍數）分開估值，加總後的隱含價值通常**高於**市場給合併體的價格。這是「隱藏價值重估」催化的來源，也是分析師平均目標價 $312.99 高於現價 ~29% 的邏輯基礎之一。

## 四、多空辯論 (Bull vs. Bear Debate)

**多方核心**
- AWS 加速 + 晶片利潤槓桿 + 廣告複利 = 營業利益成長快於營收。
- SOTP 顯示隱藏價值；估值（Fwd P/E ~32x）對此獲利軌跡並不貴。
- 多個免費選擇權提供非對稱上檔。

**空方核心**
- AI Capex 龐大，若 ROIC 不彰、FCF 轉化不佳，估值難維持。
- AWS 增速若無法突破、甚至回落，成長溢價收斂。
- 零售受總經／消費循環影響；監管（反壟斷、勞工）與 Leo/衛星等新事業拖累短期利潤率。

## 五、關鍵風險 (Key Risks — 會使論點失效)

1. **AWS 增速拐點**（最主要）：連兩季顯著減速將直接打擊估值主體。
2. **資本紀律 / FCF**：AI 資料中心 Capex 若未見對應 ROIC 與 FCF，市場信心動搖。
3. **業外損益失真**：Anthropic 等投資的公允價值波動會使 GAAP 獲利大起大落，須以營業利益判讀。
4. **監管與勞工**：反壟斷、工會、跨國稅務。
5. **總經與消費**：零售與廣告對景氣敏感。
6. **新事業拖累**：Leo 衛星、Kuiper 等前期虧損壓抑利潤率。
