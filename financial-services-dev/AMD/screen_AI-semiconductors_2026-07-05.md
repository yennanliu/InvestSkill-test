## 三、投資點子清單 (Idea Shortlist)

### ① AMD — 做多 — 「NVDA 以外唯一具規模的 AI GPU 挑戰者」
| 指標 | 數值 |
|---|---|
| 現價 / 市值 | ~$519.50 / ~$845B |
| 遠期 P/E | ~88x |
| 營收成長 (Q1'26) | +38% YoY（資料中心 +~57%） |
| 毛利率 | 53% → 財測 56% |

- **論點**：AI 加速器份額 9%→15%+；EPYC 現金牛；毛利率擴張。
- **風險**：估值極度延伸；NVDA 生態壁壘。
- **下一步**：見 [`thesis_AMD_2026-07-05.md`](./thesis_AMD_2026-07-05.md)、[`initiate_AMD_2026-07-05.md`](./initiate_AMD_2026-07-05.md)。

### ② NVDA — 做多 — 「AI GPU 龍頭 + CUDA 生態護城河」
- **論點**：~75–80% 份額、系統級整合、龍頭規模與獲利。
- **風險**：份額緩降、極高市場預期。
- **下一步**：建立完整模型與估值。

### ③ 供應鏈瓶頸持有者（代工 / HBM / 先進封裝）— 做多 — 「賣鏟子」
- **論點**：無論 NVDA 或 AMD 勝出，先進製程／封裝／HBM 產能都受惠；波動相對低。
- **風險**：資本支出循環、地緣政治（出口管制）。
- **下一步**：鎖定 CoWoS、HBM4 產能領先者。

### ④ AI 資料中心「非晶片」受惠（網通 / 電源 / 散熱）— 做多 — 「被忽略的第二層」
- **論點**：AI 機櫃功率密度飆升，帶動高速互連、液冷、電源需求；市場連結度較低。
- **風險**：客戶集中、循環性。
