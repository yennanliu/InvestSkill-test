## 二、論點支柱 (Key Pillars)

1. **AI 加速器份額成長（核心）**：AMD 是 NVDA 之外唯一具規模的替代方案。AI 加速器份額由 2025 的 ~9% 上看 2026 年底 >15%；資料中心 GPU 營收預估 2026 ~$15.6B → 2027 ~$40B → 2028 ~$63B。
2. **EPYC 伺服器 CPU 現金牛**：對 Intel 的份額續奪，Q2 財測伺服器 CPU +70% YoY，提供穩定高毛利現金流以支撐 GPU 研發投入。
3. **產品路線圖競爭力**：MI350 量產、MI400（MI455X：40 PFLOPs FP4、432GB HBM4）鎖定與 NVDA 下一代對決；ROCm 軟體生態逐步成熟。
4. **毛利率結構性擴張**：組合向資料中心傾斜，毛利率 50% → 53% → 財測 56%，帶來營運槓桿。
5. **超大廠「多供應商」需求**：雲端業者為避免單一依賴 NVDA、控制成本，主動扶植 AMD 作為第二來源。

## 三、關鍵風險 (Key Risks — 會使論點失效)

1. **估值風險（最主要）**：Fwd P/E ~88x、YTD +152%，已對完美執行定價；任何執行落差都可能引發劇烈估值壓縮。
2. **NVIDIA 競爭與生態壁壘**：NVDA 仍握 ~75–80% 份額，CUDA 軟體護城河深厚，Rubin 等下一代產品持續推進。
3. **AI GPU 放量與供應瓶頸**：HBM4、CoWoS 先進封裝產能限制可能拖累出貨。
4. **客戶集中**：AI GPU 營收高度依賴少數超大廠訂單，具波動性。
5. **景氣循環**：客戶端、遊戲、嵌入式受 PC 與工業循環影響。

## 五、估值與部位管理

- **合理價值錨點**：目標價高度分歧（$263 ~ $478 不等），且多數已落後股價；反映市場對「份額成長速度」的定價尚未收斂。
- **目標價（若論點成立）**：取決於 2027–2028 資料中心 GPU 營收兌現（$40B → $63B）；估值支撐高度依賴此成長曲線。
- **停損／退出觸發條件 (Stop-loss / Exit Triggers)**：
  - 資料中心 GPU 營收指引下修，或 MI400 需求前瞻不如預期。
  - 毛利率擴張停滯（跌破 ~53%）。
  - NVDA 於推論市場以價格／生態進一步壓制 AMD 份額。
  - 股價跌破關鍵技術支撐且伴隨放量（趨勢轉弱）。
